### Setup

- [Python](https://www.python.org) 3.13+
- [Bun](https://bun.sh) 1.2+
- [Dart](https://dart.dev/get-dart) 3.7.2+
- [Flutter](https://flutter.dev) 3.29.2+ (for [flyweight](/patterns/structural/flyweight/))

```bash
# Python
uv sync --all-packages

# TypeScript
bun install
```
